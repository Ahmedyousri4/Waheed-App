# Product Rules — Waheed

## Domain
Men's suits e-commerce (Arabic market, RTL-first).

## Key Rules
1. **RTL First** — UI is Arabic-first. Default locale is `ar`.
2. **Inter + Cairo** — Use Inter for Latin/numbers, Cairo is available for Arabic body.
3. **Currency** — Prices displayed with comma formatting (e.g., "2,450").
4. **Product identity** — Products are matched by image + title combination.
5. **Cart behavior** — Add increments quantity; decrement at 1 removes item.
6. **Favorites behavior** — Toggle on/off (no quantity concept).
