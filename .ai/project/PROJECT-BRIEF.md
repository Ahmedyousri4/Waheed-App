# Project Brief — Waheed Hassan Men's Suits

## Product
Arabic-first (RTL) e-commerce mobile application for men's suits, including:
- Product browsing & categories
- Product details with gallery
- Shopping cart
- Favorites / wishlist
- Custom suit measurements
- Checkout with address & payment
- Order review

## Primary Language & Locale
- Arabic (RTL)
- Secondary locale support: English

## Platform Targets
- Android
- iOS
- (Web, Linux, macOS, Windows dirs exist but not primary)

## Fonts
- **Inter** — Primary (Latin/numbers), weights 400–900
- **Cairo** — Arabic body text, weights 400–700

## Status
Active development. Approximately 56 source files, ~269 KB total code.
